Fun With Fonts

Three ways to animate how lettering appears on screen. Each demo is one self-contained HTML file.

  • Top-down wipe

    A CSS clip rectangle slides down and reveals the word from the top.

  • Stroke trace

    An SVG dash slides along each letter's outline so it draws itself, then the fill fades in.

  • Spray paint

    A canvas nozzle sweeps in rows and fires dots through a stencil of the word, with overspray and drips.
